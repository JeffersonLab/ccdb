# DataCite 4.5 JSON schema

`datacite-v4.5.json` is the JSON schema of DataCite metadata 4.5 from the Invenio DataCite library
(https://github.com/inveniosoftware/datacite, `datacite/schemas/datacite-v4.5.json`, fetched 2026-11-03), under the
Revised BSD License in `LICENSE`. `python/tests/unit_test_export_tag.py` validates the record `ccdb export tag`
writes against it. CCDB itself does not read it at run time.
