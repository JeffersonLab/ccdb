# Java API

The Java API is ready to use without compilation. `ccdb.jar` is located in the `$CCDB_HOME/java`
directory.

## "Hello world" project tutorial

This tutorial shows how to create a CCDB "Hello world" project using the IntelliJ IDE.

Prerequisites:

1. IntelliJ IDEA is installed.
2. CCDB is installed and the DB is set up. This means that `ccdb ls` gives a proper result.

> P.S. If the IDE shows errors while the project compiles, **File → Invalidate Caches** usually solves
> the situation.
